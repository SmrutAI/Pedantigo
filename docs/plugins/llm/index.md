# LLM Plugins

Coming soon. Pedantigo already provides `Schema()`/`SchemaJSON()`/
`SchemaLLM()` for LLM tool-use schema generation in core (`pdcore`). A
dedicated LLM plugin category is planned for tighter integrations (e.g.
provider-specific structured-output adapters) using the same
`pdcore.UnmarshalInto` pattern as the [Echo Binder](/plugins/web/echo).
